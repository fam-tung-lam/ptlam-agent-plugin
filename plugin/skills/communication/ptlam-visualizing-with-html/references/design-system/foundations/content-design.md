# Content design

This file owns visible wording, meaning that survives translation, alternative
text, and access to anything shortened.

Use direct verbs, concrete nouns, sentence case, and one action per control.
Name the actor, action, state, or result with short labels. Keep essential
labels visible instead of hiding them in a tooltip, and put qualifications
beside the visual they limit.

Translate meaning, not sentence structure. Avoid idioms in controls and labels
that must survive translation. Keep notifications brief and actionable.

Describe an informative image by its purpose and context, usually within 125
characters. Do not start with "image of" or list pixels. Put essential facts in
nearby text when a caption or diagram label carries them better.

Shorten text only when the full value stays reachable through a visible
disclosure, a link, or a keyboard-accessible tooltip. An ellipsis with no route
to the rest is not a complete label.

Source snapshot: Material 3 content-design, writing, alt-text, and
text-truncation guidance, captured with Firecrawl on 2026-08-07.
