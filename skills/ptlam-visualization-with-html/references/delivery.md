Return the single `.html` file at the resolved destination. Report what changed
and where, the selected visual grammar, whether the analogy branch ran, the
validator command and result, the browser conditions inspected, and any behavior
that remains unverified.

resource, and the handoff separates static checks from rendered browser
evidence.
